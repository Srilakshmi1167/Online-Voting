&#x20;Online Voting System



Project Overview

The Online Voting System is a web-based application developed to conduct student elections digitally. It allows students to register, log in, nominate candidates, and cast their votes securely.



Technologies Used

\- Java

\- Spring Boot

\- Spring Security

\- JWT Authentication

\- Spring Data JPA

\- H2 Database

\- HTML

\- CSS

\- JavaScript

\- Maven



&#x20;Features

\- Student Registration and Login

\- JWT-based Authentication

\- Student Nomination

\- Candidate Management

\- Secure Voting System

\- Vote Management

\- Admin Functionality



&#x20;Project Structure

\- `src/main/java` – Java source code

\- `src/main/resources` – Application configuration

\- HTML files – Frontend pages

\- `pom.xml` – Maven dependencies



&#x20;How to Run the Project



1\. Install Java 17 or later.

2\. Open the project in Eclipse or IntelliJ IDEA.

3\. Import the project as a Maven project.

4\. Run `ElectionApplication.java`.

5\. Open your browser and visit:



&#x20;  `http://localhost:8080`



&#x20;Database

The project uses an H2 in-memory database.
